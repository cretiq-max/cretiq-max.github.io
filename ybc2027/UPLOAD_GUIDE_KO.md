# YBC 졸업 기념 홈페이지 — 사진 업로드 안내

새 홈페이지 주소: https://cretiq-max.github.io/ybc2027/

## 사진 업로드 위치
**반드시 `ybc2027/images/` 폴더에 올리세요.** 예전의 최상위 `images/` 폴더가 아닙니다.

- 대표사진: `ybc2027/images/hero01.jpg`, `hero02.jpg`, `hero03.jpg`
- 일반사진: `ybc2027/images/photo001.jpg`부터 `photo100.jpg`까지
- 없는 사진은 자동으로 숨겨집니다.
- 확장자는 모두 소문자 `.jpg` 사용.
- 긴 변 1600~2000px 정도로 압축 권장.

## 업로드 절차
1. GitHub의 [ybc2027/images 폴더](https://github.com/cretiq-max/cretiq-max.github.io/tree/main/ybc2027/images)를 엽니다.
2. **Add file → Upload files**를 누릅니다.
3. 파일명이 정확한지 확인한 후 업로드합니다.
4. **Commit changes**를 누릅니다.
5. 몇 분 후 [홈페이지](https://cretiq-max.github.io/ybc2027/)를 새로 고침해 확인합니다.

현재 저장소는 GitHub Pages `main / (root)`를 사용합니다. 별도 저장소를 만들거나 GitHub Pages 설정을 변경할 필요가 없습니다.

## 공개 범위
학생 사진도 인터넷에 공개됩니다. 사진 촬영 및 공개에 관한 본인 동의와 학교의 규정을 확인하세요.
